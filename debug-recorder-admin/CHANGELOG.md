## [1.0.0] - 2024-12-02

### 추가됨

#### 핵심 기능
- **녹화방 관리**
  - 디버깅 녹화방 생성 및 관리
  - 네트워크 요청, 콘솔 로그, DOM 변경 실시간 캡처
  - 스크린샷 및 동영상 녹화 기능
  - 고유 링크를 통한 녹화방 공유

- **이슈 연동**
  - 대시보드에서 직접 이슈 티켓 생성
  - 프로젝트별 설정 가능한 티켓 템플릿
  - 녹화방 링크 자동 첨부
  - 커스텀 필드 지원: Epic, 컴포넌트, 라벨, 담당자

- **네트워크 리라이트**
  - 테스트를 위한 API 요청/응답 데이터 수정
  - HTTP 상태 코드 변경
  - 쿼리 파라미터 조작
  - 백엔드 변경 없이 엣지 케이스 테스트

- **분석 대시보드**
  - 녹화방 생성 추이 (일별/주별/월별)
  - 티켓 생성 통계
  - 팀 활동 메트릭
  - Recharts를 활용한 인터랙티브 차트

- **사용자 관리**
  - 사용자 프로필 설정
  - 모바일 테스트용 디바이스 등록
  - 사용자당 여러 티켓 템플릿 지원
  - 직군 분류 (QA, PM, PD, DEV, OTHER)

- **스프레드시트 연동**
  - 스프레드시트에서 티켓 템플릿 설정 가져오기
  - 담당자, 컴포넌트, 라벨 매핑 지원
  - TC(테스트 케이스) 시트 자동 파싱

#### 기술적 특징
- **모던 기술 스택**
  - TypeScript 5.9가 적용된 React 19
  - 빠른 개발 및 최적화된 빌드를 위한 Vite 7
  - UI 컴포넌트용 Ant Design 6
  - 데이터 페칭을 위한 TanStack Query
  - 폼 관리를 위한 React Hook Form

- **코드 품질**
  - 완전한 TypeScript 적용
  - flat config를 사용한 ESLint 9
  - 코드 포맷팅을 위한 Prettier
  - 코드 스플리팅이 적용된 최적화된 프로덕션 빌드

- **개발자 경험**
  - 자동 생성 인증서를 사용한 HTTPS 개발 서버
  - 핫 모듈 교체 (HMR)
  - 포괄적인 환경 설정
  - 상세한 API 문서

### 변경됨
- 전용 UI 라이브러리에서 Ant Design으로 마이그레이션
- 모든 의존성을 최신 버전으로 업데이트
- 회사 특화 브랜딩 및 코드 제거
- 문서를 영문에서 한글로 변환

### 제거됨
- 전용 `@atelier-mold/admin` 의존성
- 회사 특화 배포 설정
- 내부 인증 의존성

### 보안
- 하드코딩된 자격 증명 및 URL 제거
- 모든 설정을 환경 변수로 외부화
- 안전한 설정을 위한 `.env.example` 템플릿 추가

## 업그레이드 가이드

### 내부 버전에서 1.0.0으로

내부 회사 버전에서 마이그레이션하는 경우:

1. **의존성 업데이트**
   ```bash
   rm -rf node_modules pnpm-lock.yaml
   pnpm install
   ```

2. **환경 변수 업데이트**
   - `.env.example`을 `.env`로 복사
   - 모든 필수 변수 설정
   - 회사 특화 변수 제거

3. **Import 문 업데이트**
   - `@atelier-mold/admin` import를 `antd`로 교체
   - Ant Design에 맞게 컴포넌트 API 업데이트

4. **인증 업데이트**
   - 인증 서비스에 맞게 `VITE_ADMIN_BFF_HOST` 설정
   - 또는 커스텀 인증 구현
